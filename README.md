# Insurance Charges Analysis

## Project Overview
This project analyzes insurance customer data to identify factors affecting medical insurance charges.

## Features
- Exploratory Data Analysis (EDA)
- Data Cleaning
- Feature Engineering
- Feature Selection
- Statistical Analysis

## Technologies Used
- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Scikit-learn

## Key Findings
- Smoking status significantly increases insurance charges.
- Age and BMI strongly influence costs.
- Obesity is associated with higher charges.
